## Reflection

### 1. Commit History

My commit history shows that I can organize my work and make changes step by step. The descriptive commit messages make it easier to understand what I worked on and show that I am keeping track of my progress.

### 2. Using Git

Using Git changes how I approach editing a script because I can save my progress as I work. Instead of making all my changes at once, I can commit smaller updates and go back to an earlier version if something goes wrong.

### 3. Personal .gitignore Addition

One thing I would add to my `.gitignore` is `__pycache__/`, which stores Python files created automatically when running code. These files are not necessary for sharing my project, so ignoring them keeps my repository organized and prevents unnecessary files from being tracked.
